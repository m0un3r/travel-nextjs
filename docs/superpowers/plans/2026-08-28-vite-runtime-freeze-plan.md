# Vite Runtime Freeze — Vite+React Static Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform `cloned_site/` (Framer Travelio) into `travelio-vite/dist/` pixel-perfect Vite+React 19 static site (52 routes, 81 framerusercontent chunks verbatim) for Cloudflare Pages.

**Architecture:** `transpile_to_vite.py` copies `cloned_site/assets` + `cloned_site/framerusercontent` verbatim to `travelio-vite/public/`, generates `src/pages/` thin shells with `dangerouslySetInnerHTML` + `useEffect` Framer hydration per `cloned_site/<route>/**/index.html`, uses `react-router-dom` `createBrowserRouter` + Vite `build.outDir:"dist"` for static `dist/<route>/index.html` trailingSlash folders.

**Tech Stack:** Vite 5 + React 19.1 + react-router-dom 6 + TypeScript 5.6 + Framer Motion (`motion.BTFsJANr.mjs`)

## Global Constraints

- One-time fork — no re-sync, no CMS writeback
- Pixel-perfect — verbatim Framer `data-framer-hydrate-v2`, `__framer__handoverData`, breakpoint hashes `72rtr7/ha1oc5/1hqw9z1`
- Verbatim copy — `cloned_site/assets` (648 files) + `cloned_site/framerusercontent` (81 files: 74 mjs +5 js +2 json, SHA256) → `public/` no optimization, no rename
- `vite.config.ts` must have `base:'/'`, `build:{outDir:'dist', assetsDir:'assets'}` — `dist/` deploy-ready
- Per-slug shells — not generic home dump; `ToursSlug` 19, `LocationSlug` 9, `BlogSlug` 7, `CategorySlug` 5, `LegalSlug` 2
- `src/index.css` must NOT contain `[data-framer-appear-id]{opacity:1 !important}` blanket
- `dist/` must contain 52 HTML matching `cloned_site/**/index.html`

```python
# transpile_to_vite.py
import shutil, pathlib, hashlib
def sync_assets(src_root, dst_root):
    src = pathlib.Path(src_root) / "framerusercontent"
    dst = pathlib.Path(dst_root) / "public/framerusercontent"
    if dst.exists(): shutil.rmtree(dst)
    shutil.copytree(src, dst)
    # hash verify
    for f in src.rglob("*"):
        if f.is_file():
            rel = f.relative_to(src)
            assert hashlib.sha256(f.read_bytes()).hexdigest() == hashlib.sha256((dst/rel).read_bytes()).hexdigest()
```
